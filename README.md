# Ralphie Studios

**Independent development studio creating games, apps and digital sports experiences.**

🌐 [ralphiestudios.com](https://ralphiestudios.com)

Ralphie Studios is an independent studio focused on building projects with a strong connection to sport, gameplay and authentic user experiences.

The studio is currently developing **Wheelchair Rugby League**, a sports game built specifically around the wheelchair version of Rugby League, alongside **BaizeBoard**, a live digital snooker scoreboard available on web and Android.

---

## Projects

### 🏉 Wheelchair Rugby League

**The first Wheelchair Rugby League video game.**

Wheelchair Rugby League is the flagship Ralphie Studios project, currently in **pre-alpha development** using **Unreal Engine 5**, primarily with Blueprints.

The goal is not to adapt a standing Rugby League game to wheelchairs. The game is being designed around the real mechanics, movement, contact and tactical decisions of Wheelchair Rugby League from the ground up.

Current gameplay work includes:

- Wheelchair acceleration, momentum and grip
- Sprinting and seated push animation
- Steering and chair-first handling
- Player body positioning and leaning
- Agility-driven lean range
- Lean-assisted turning
- Ball pickup and possession
- Left and right passing
- No-forward-pass rules
- Kicking
- Manual try scoring
- Home and Away scoring
- Scoreboard and match clock
- Player data and gameplay attributes

Current development is moving toward:

- Chair stability
- Wheel lift and tipping
- Recovery mechanics
- Shoulder-tag tackling
- Contact and big-wheel defence
- Match restarts
- Pass power and teammate targeting
- Expanded kicking mechanics
- 5v5 teams and rosters
- AI and player switching
- Individual player traits
- Full match structure
- Venues, crowds and officials
- Replays and broadcast-style presentation

Development updates are published through the WRL Development Log:

➡️ [ralphiestudios.com/wrl](https://ralphiestudios.com/wrl)

## Ralphie Studios Website

The Ralphie Studios website is a lightweight static site built with:

- HTML5

## WRL Development Philosophy

The Wheelchair Rugby League project is being built around one core principle:

> **Every push should matter. Every angle should matter. Every hit should change the next decision.**

Player ratings are intended to affect gameplay rather than exist as decorative numbers.

Attributes currently planned or in use include:

- Speed
- Acceleration
- Agility
- Stamina
- Handling
- Tackling
- Aggression
- Passing
- Kicking
- Recovery
- Overall

For example, **Agility already affects the player's functional upper-body lean range**, meaning different players can physically behave differently on court.

## Development Log

The WRL Development Log documents not just *what* has been added, but *why* each mechanic matters to Wheelchair Rugby League.

Entries are structured around:

1. Why the mechanic matters in Wheelchair Rugby League
2. How it works in-game
3. Player/stat interaction
4. Unreal Engine development notes
5. What comes next

Current topics include:

- **Body Position Matters** — Leaning & Agility
- **Using Your Weight** — Leaning and chair handling
- **Finding the Tipping Point** — Stability and tipping
- **What Counts as a Tackle?** — Tags, contact and falls

## Local Development

The website does not require a framework or build process.

You can open `index.html` directly in a browser, although running a simple local web server is recommended so relative paths behave consistently.

For example:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
